# flappy

终端版 flappy-bird 克隆：重力物理、拍打、管道缺口、碰撞判定，外加一个能自己玩的简单 AI 演示。

## 玩法

- `python -m flappy` — 交互模式：每按一次回车拍打一下，`q` 退出
- `python -m flappy --auto` — 无头自动演示（AI 玩 500 帧）
- `python -m flappy --auto --frames 1000 --seed 7` — 指定帧数和种子
- `python -m flappy --seed 42` — 固定管道序列

## 物理参数

- 重力 `GRAVITY = 0.45` /帧²，拍打初速 `FLAP_V = -1.4` /帧
- 管道宽 4 格、缺口高 6 格、间距 16 帧
- **设计取舍**：相邻管道的缺口中心变化限制在 ±3.5 格内（`MAX_GAP_DELTA`）。
  真实 flappy 类游戏都会约束缺口渐变，否则以本作的垂直机动性（约每 4 帧爬 2.2 格）
  在 12 帧的窗口内追不上 11 格的跳变。这不是 bug，是可玩性设计。

## 验证记录（真实运行）

- `py_compile` 通过
- 单元测试：拍打抬升速度 / 重力下拉 / 管道碰撞（缺口外撞、缺口内过）/
  过缺口得分 / 撞地板与天花板结束 —— 全部通过
- `--auto --frames 500`：10 个种子（0,1,5,7,8,13,42,99,100,123）**全部 500 帧存活，得分 29**，无崩溃
- AI 策略：锁定最近管道，下落且低于缺口中心时拍打；调参过程如实记录——
  初版拍打过猛（上冲 9.6 格 vs 缺口 6 格）必撞管，遂减弱拍打并约束缺口渐变

## 已知局限

- **无实时键盘输入**：交互是"按回车拍打"的回合制，不是真正的实时游戏；
  要做实时版需要 curses 或类似库接按键事件
- 鸟按质点判定碰撞，无旋转动画
- AI 只会跟缺口中心，不做预判加速
- 需要 Python 3.10+
